# Trip — отчёт о поездке

Программа выводит отчёт о расходах в поездке: количество записей, общую сумму и среднюю трату.

## Создание виртуального окружения

### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Windows (PowerShell)
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python trip.py
```

## Результат работы

Программа печатает:

```text
ОТЧЁТ ПО ПОЕЗДКЕ
--------------------------------
записей: 10
всего потрачено: 7900 ₽
средняя трата: 790.00 ₽
```

Заголовок отчёта выделяется жирным зелёным цветом с помощью библиотеки Rich.

Расчёты общей и средней суммы вынесены в отдельный модуль `calculator.py`.
