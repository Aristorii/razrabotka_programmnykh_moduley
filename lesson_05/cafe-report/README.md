# Cafe Report — отчёт по заказам кофейни

Учебный проект на Python: программа читает заказы из CSV-файла и выводит отчёт
с количеством заказов, общей выручкой, средним чеком и суммами по официантам.

## Требования
- Python 3.10 или новее
- Внешние библиотеки для запуска не нужны
- Для проверки типов можно отдельно установить `mypy`

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
python -m venv .venv
```

Активируйте виртуальное окружение:

**Windows PowerShell**
```powershell
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Запустите программу:

```bash
python -m app.main
```

## Проверка тестов

```bash
python -m unittest discover -s tests -v
```

## Проверка типов (необязательно)

```bash
python -m pip install mypy
mypy app
```

## Ожидаемый результат

----------------------------------
Заказов: 6

Средний чек: 617,00 ₽
----------------------------------
Анна Петрова      770,00 ₽
Игорь Смирнов     1 793,00 ₽

В проекте используются аннотации типов, функции вынесены в отдельные модули,
а тесты проверяют расчёты и форматирование отчёта.
