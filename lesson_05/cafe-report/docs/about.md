# Cafe Report

Программа читает заказы кофейни из файла `data/orders.csv` и печатает отчёт:
количество заказов, выручку, средний чек и суммы по официантам.

Нужен Python 3.10 или новее. Внешние библиотеки не используются.

## Запуск

Команды выполняются из корня проекта:

```bash
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows для создания окружения также можно использовать `py -m venv .venv`.
