# Text Kit

Text Kit — учебная программа с небольшими функциями для обработки строк, расчётов, проверки данных и работы с датами. После разделения на модули программа сохраняет исходный вывод.

## Структура проекта

```text
text-kit/
├── README.md
├── app/
│   ├── __init__.py
│   ├── main.py
│   ├── services/
│   │   ├── __init__.py
│   │   ├── statistics.py
│   │   └── validation.py
│   └── utils/
│       ├── __init__.py
│       ├── dates.py
│       └── text.py
└── tests/
    ├── test_dates.py
    ├── test_statistics.py
    ├── test_text.py
    └── test_validation.py
```

## Почему функции разделены именно так

Функции распределены по ответственности. `utils/text.py` содержит универсальные операции со строками, а `utils/dates.py` — преобразование и проверку дат. В `services/statistics.py` находятся расчёты для данных проекта, а `services/validation.py` — проверки электронной почты, телефона и пароля. Модуль проверки данных использует `clean_spaces` из `utils/text.py`.

## Запуск

Из корневой папки `text-kit` выполните:

```bash
python -m app.main
```

## Проверка

```bash
python -m unittest discover -s tests -v
```

Проект использует только стандартную библиотеку Python, дополнительные зависимости не нужны.
